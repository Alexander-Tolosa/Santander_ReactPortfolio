# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

User-specified: Next.js (App Router) + TypeScript + Tailwind + shadcn/ui + lucide-react + GSAP, React Router in Data Mode (mounted in one Next.js catch-all client route), React Bootstrap components. Source: the brief and the routing answer in the build session.

## Users

Course instructors grading a React portfolio against a rubric (3+ pages in separate .tsx files, 5+ React Bootstrap components, one shared Navigation, responsive layout), and recruiters or peers who view it afterwards.

## Product Purpose

A student personal portfolio that doubles as a rubric submission. Success: every rubric line is visibly met and findable, and the site feels unique and designed.

## Capabilities and Constraints

- All personal information is placeholder (fictional name, projects, skills, contact). Marked for replacement.
- No past-portfolio source was supplied (the brief's link was a placeholder), so nothing was imported from one.
- No Ferrari logo, prancing horse or other trademarks. Ferrari-inspired showcase look only.

## Brand Commitments

Pinned by the user: the visual theme is a Ferrari-style car showcase (Rosso Corsa red, carbon black, restrained Giallo yellow, showroom drama).

## Evidence on Hand

None. No real projects, testimonials or metrics. Do not fabricate claims; all demonstration content is labeled placeholder.

## Product Principles

1. Rubric coverage is visible, not hidden.
2. Placeholder content is honest and easy to replace (one data file).
3. Motion is purposeful and respects reduced-motion.

## Accessibility & Inclusion

WCAG AA contrast, keyboard navigation, visible focus, reduced-motion support.
